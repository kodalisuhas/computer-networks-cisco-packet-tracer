# Computer Networks — Cisco Packet Tracer

A hands-on Computer Networks project implementing and analyzing networking concepts using Cisco Packet Tracer.

## Overview

This repository contains practical implementations of fundamental computer networking concepts, including network topologies, LAN, MAN, WAN, VLAN, application-layer services, DNS, TCP, and UDP.

Each experiment includes:

- Cisco Packet Tracer `.pkt` implementation
- Network configuration
- Conceptual documentation
- Verification and testing
- Packet Tracer screenshots

## Experiments

| No. | Experiment | Implementation |
|---|---|---|
| 01 | Cisco Commands | Common Cisco networking commands |
| 02 | Network Topologies | Bus, Star, Ring, Mesh, Tree |
| 03 | LAN | Local Area Network |
| 04 | MAN | Metropolitan Area Network |
| 05 | WAN | Wide Area Network |
| 06 | VLAN | Virtual Local Area Network |
| 07 | HTTP / HTTPS | Web server communication |
| 08 | FTP | File Transfer Protocol |
| 09 | DNS | Domain Name System |
| 10 | TCP / UDP | Transport layer protocols |
